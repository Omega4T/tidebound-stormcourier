An original sailing adventure. Mark two channel signals per crossing, then deliver three lantern-fuel crates across an archipelago before the 150-second storm closes the coast. Reefs, moving wrecks, currents and telegraphed lightning test your route. Salvage funds repairs, armor or faster canvas at lighthouse docks. Sheltered passage trades speed for safety; the express contract grants 25% more speed and two extra delivery scrap, but impacts deal 30% more damage and lightning comes sooner.

## Play locally

Run `python3 -m http.server 8080 --directory game`, then open localhost:8080. No build step, external assets or network service is required.

WASD/arrows steer; Space uses full sail and stamina; E docks; C opens the chart; P pauses; M toggles audio; R restarts. Audio begins after a click.

## Validate

`node --test tests/*.mjs` runs simulation regressions. `MAKEFUN_OUTPUT_DIR=../out node main.ts` copies the game and real screenshots and generates its dossier with the unchanged official library. The actual browser campaign has been completed through normal keyboard input. See parent QA evidence for limits; local tests are not an official judge score.

All coastal art is generated by our own Canvas code; sound is original WebAudio synthesis. Code is split into campaign, regions, sailing, coastal art, audio and browser control modules.
